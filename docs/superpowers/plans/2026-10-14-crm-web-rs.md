# crm-web-rs (Rust kópia crm-web) – implementačný plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Funkčná kópia 1:1 zmigrovaného blacklistu (`crm-web/`) v Ruste (`crm-web-rs/`), v Dockeri pod `/crm-rs` vedľa Liferay, Java appky, SSO mocku a Redisu.

**Architecture:** axum handlery = Java controllery (render GET, action POST + PRG, resource AJAX). Typové extraktory `Require<View|Modify>` nahrádzajú interceptor + `@RequiresPrivilege`. askama šablóny = JSP s helpermi `Tags` (= `portal:*`/`common:*` tagy). Zdieľaná session cez Redis hash s rovnakým JSON kontraktom, identita zo `SSO_ID` cez SSO API. Texty aj statické súbory sa berú priamo z `crm-web` (jeden zdroj).

**Tech Stack:** Rust 1.98.1 (edícia 2024), axum 0.8, askama 0.16, tokio 1, tower-http 0.7, redis 1.7, reqwest 0.13, serde/serde_json, chrono 0.4, regex 1, uuid 1, form_urlencoded 1, tracing.

**Spec:** `docs/superpowers/specs/2026-10-14-crm-web-rs-design.md`

## Global Constraints

- `crm-web/`, `legacy/`, `sso-mock/` sa **nemenia**; `input/` je read-only a nikdy sa nečíta do build kontextu.
- Prefix URL `/crm-rs`, port na hoste `8082`, vlastná cookie `CRM_RS_SESSION` s `Path=/crm-rs; HttpOnly; SameSite=Lax`.
- Redis: hash `crm:session:{SSO_ID}`, TTL 1800 s (obnoví sa pri čítaní aj zápise), polia `APP_MESSAGES`, `APP_BLACKLIST_LAST_CRITERIA`, `APP_LAST_VIEWED_RECORD`, flag `crm:flags:session-read-source`; JSON camelCase ako Java records, enumy ako reťazce, neznáme polia sa ignorujú; timeout 500 ms.
- SSO: `GET {CRM_SSO_APIURL}/api/sessions/{id}`, 404 = neprihlásený, iná chyba/timeout (1 s connect, 2 s celkovo) = SSO nedostupné; `SSO_ID` platí len v tvare `[A-Za-z0-9-]{1,64}`.
- Bez `unwrap()`/`expect()` na vstupe od používateľa a na I/O za behu (povolené: konštanty, štart, testy).
- Identifikátory anglicky; komentáre **po slovensky**, vysvetľujú rozhodnutie a Java/legacy ekvivalent, nie čo kód robí. Každá `pub fn` má `///` komentár.
- Testy: `should_x_when_y` (snake_case), nad testom `///` popis po slovensky (ekvivalent `@DisplayName`). Pokryť happy path, chýbajúci/neplatný vstup, prázdne kolekcie, hranice.
- askama: v šablónach žiadne vlastné filtre ani makrá; metódam sa odovzdávajú len literály, `&str` a `Copy` hodnoty (`String` cez `.as_str()`); `|safe` len pre HTML z `FieldErrors`.
- Build a testy len v Dockeri: `bash crm-web-rs/test.sh` (lokálny Rust netreba). Docker Desktop musí bežať.
- **Necommitovať** – commity robí používateľ. Pri „checkpoint“ krokoch len skontroluj `git status`. Nikdy `git push`.
- Anonymizácia podľa `CLAUDE.md` (žiadne mená klienta, interné URL, kód z `input/`).

```rust
//! Konfigurácia z premenných prostredia – defaulty zodpovedajú `application.properties` Java verzie (lokálny beh),
//! docker-compose prepíše SSO a Redis.

use std::net::SocketAddr;

/// Nastavenie appky (Java: `application.properties` + premenné prostredia v compose).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Config {
    pub bind: SocketAddr,
    pub sso_api_url: String,
    pub sso_login_url: String,
    pub redis_url: String,
    /// Statické CSS/JS sa servírujú priamo z crm-web (jeden zdroj s Java appkou); v Dockeri `/app/static`.
    pub static_dir: String,
}

impl Config {
    /// Konfigurácia z prostredia procesu.
    pub fn from_env() -> Self {
        Self::from_lookup(|name| std::env::var(name).ok())
    }

    /// Testovateľné jadro `from_env` – hodnoty premenných dodá volajúci.
    pub fn from_lookup(lookup: impl Fn(&str) -> Option<String>) -> Self {
        let get = |name: &str, default: &str| {
            lookup(name).filter(|v| !v.trim().is_empty()).unwrap_or_else(|| default.to_string())
        };
        let bind_text = get("CRM_BIND", "0.0.0.0:8080");
        let bind = bind_text.parse().unwrap_or_else(|_| {
            tracing::warn!("Neplatné CRM_BIND '{bind_text}', použije sa 0.0.0.0:8080");
            SocketAddr::from(([0, 0, 0, 0], 8080))
        });
        Self {
            bind,
            sso_api_url: get("CRM_SSO_APIURL", "http://localhost:8090/sso").trim_end_matches('/').to_string(),
            sso_login_url: get("CRM_SSO_LOGINURL", "/sso/login"),
            redis_url: format!("redis://{}:{}/", get("CRM_REDIS_HOST", "localhost"), get("CRM_REDIS_PORT", "6379")),
            static_dir: get("CRM_STATIC_DIR", "../crm-web/src/main/resources/static"),
        }
    }
}
```

```rust
//! Hodiny ako závislosť (Java `ClockConfig` bean) – pravidlá s „dnešným dátumom“ sa testujú s pevným časom.

use chrono::{Local, NaiveDate, NaiveDateTime};

/// Zdroj aktuálneho času.
pub trait Clock: Send + Sync {
    /// Aktuálny lokálny čas.
    fn now(&self) -> NaiveDateTime;

    /// Dnešný dátum.
    fn today(&self) -> NaiveDate {
        self.now().date()
    }
}

/// Systémové hodiny (v kontajneri UTC rovnako ako Java image).
pub struct SystemClock;

impl Clock for SystemClock {
    fn now(&self) -> NaiveDateTime {
        Local::now().naive_local()
    }
}

/// Pevný čas pre testy.
pub struct FixedClock(pub NaiveDateTime);

impl Clock for FixedClock {
    fn now(&self) -> NaiveDateTime {
        self.0
    }
}
```

```rust
//! Texty UI. Jeden zdroj s Java appkou: `crm-web/.../messages.properties` sa vloží pri kompilácii,
//! `messages-rs.properties` prepíše len to, čím sa Rust appka líši.

use std::collections::HashMap;
use std::fmt::Display;

const BASE: &str = include_str!("../../../crm-web/src/main/resources/messages.properties");
const OVERRIDES: &str = include_str!("../../messages-rs.properties");

/// Preklady podľa kľúča (Java: Spring `MessageSource`).
#[derive(Debug, Clone)]
pub struct Messages {
    texts: HashMap<String, String>,
}

impl Messages {
    /// Texty crm-web + rozdiely Rust appky.
    pub fn load() -> Self {
        Self::from_sources(&[BASE, OVERRIDES])
    }

    /// Neskorší zdroj prepíše skorší (ako poradie basenames v Spring `MessageSource`).
    pub fn from_sources(sources: &[&str]) -> Self {
        Self { texts: sources.iter().flat_map(|source| parse(source)).collect() }
    }

    /// Text kľúča; chýbajúci kľúč je viditeľný `??kľúč??` + warn (Java `MessageTag`).
    pub fn get(&self, key: &str) -> String {
        match self.texts.get(key) {
            Some(text) => text.clone(),
            None => {
                tracing::warn!("Chýba i18n kľúč '{key}'");
                format!("??{key}??")
            }
        }
    }

    /// Text s argumentmi `{0}`, `{1}`… – podmnožina `MessageFormat`, ktorú texty používajú (bez apostrofov).
    pub fn format(&self, key: &str, args: &[&dyn Display]) -> String {
        args.iter()
            .enumerate()
            .fold(self.get(key), |text, (i, arg)| text.replace(&format!("{{{i}}}"), &arg.to_string()))
    }
}

/// Formát Java properties v rozsahu, ktorý súbor používa (bez pokračovacích riadkov a escape sekvencií).
fn parse(source: &str) -> Vec<(String, String)> {
    source
        .lines()
        .map(str::trim_start)
```

```rust
/// Enum s menom ako v Jave (`ACTIVE`) – meno ide do formulárov, i18n kľúčov, JSP atribútov aj JSON.
macro_rules! named_enum {
    ($(#[$meta:meta])* $name:ident { $($variant:ident => $text:literal),+ $(,)? }) => {
        $(#[$meta])*
        #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
        pub enum $name { $($variant),+ }

        impl $name {
            /// Všetky hodnoty v poradí deklarácie (Java `values()`).
            pub const ALL: &'static [$name] = &[$($name::$variant),+];

            /// Meno ako v Jave (`name()`).
            pub fn name(self) -> &'static str {
                match self { $($name::$variant => $text),+ }
            }

            /// Hodnota podľa Java mena, alebo `None`.
            pub fn from_name(name: &str) -> Option<Self> {
                Self::ALL.iter().copied().find(|value| value.name() == name)
            }
        }
    };
}
```

```rust
//! ACL – v legacy vlastná ACL služba backendu; demo zachováva model „privilégium na operátora“ (security sa nemení).

use std::collections::{HashMap, HashSet};

use crate::session::identity::OperatorUser;

named_enum!(
    /// Privilégiá – mená sa v šablónach používajú ako reťazec, rovnako ako atribút `privilegeType` v JSP.
    Privilege {
        BlacklistView => "BLACKLIST_VIEW",
        BlacklistModify => "BLACKLIST_MODIFY",
        Deactivation => "DEACTIVATION",
    }
);

/// Port na ACL (Java `AclService`).
pub trait AclService: Send + Sync {
    /// Všetky privilégiá operátora.
    fn privileges_of(&self, operator: &OperatorUser) -> HashSet<Privilege>;

    /// Má operátor privilégium?
    fn has_privilege(&self, operator: &OperatorUser, privilege: Privilege) -> bool {
        self.privileges_of(operator).contains(&privilege)
    }
}

/// Pevné privilégiá demo operátorov (loginy zodpovedajú SSO mocku).
pub struct InMemoryAclService {
    by_login: HashMap<&'static str, HashSet<Privilege>>,
}

impl Default for InMemoryAclService {
    fn default() -> Self {
        let by_login = HashMap::from([
            ("citatel", HashSet::from([Privilege::BlacklistView])),
            ("spravca", Privilege::ALL.iter().copied().collect()),
        ]);
        Self { by_login }
    }
}

impl AclService for InMemoryAclService {
    fn privileges_of(&self, operator: &OperatorUser) -> HashSet<Privilege> {
        self.by_login.get(operator.login.as_str()).cloned().unwrap_or_default()
    }
}
```

```rust
//! REST klient SSO portálu. Legacy mal „provided“ API JAR v classloaderi portálu; Java aj Rust appka volajú
//! ten istý endpoint priamo. Krátke timeouty – SSO sa pýta pri každom requeste.

use std::time::Duration;

use reqwest::StatusCode;
use serde::Deserialize;

use crate::BoxFuture;
use crate::session::identity::{CustomerContext, OperatorUser, SsoApi, SsoIdentity, SsoUnavailable};

/// HTTP klient na `{api}/api/sessions/{id}`.
pub struct SsoClient {
    http: reqwest::Client,
    api_url: String,
}

/// Tvar odpovede sso-mocku.
#[derive(Deserialize)]
struct SessionView {
    operator: OperatorUser,
    customer: CustomerContext,
}

impl SsoClient {
    /// Klient s timeoutmi ako Java (1 s spojenie, 2 s celý request).
    pub fn new(api_url: &str) -> Result<Self, SsoUnavailable> {
        let http = reqwest::Client::builder()
            .connect_timeout(Duration::from_secs(1))
            .timeout(Duration::from_secs(2))
            .build()
            .map_err(|e| SsoUnavailable(e.to_string()))?;
        Ok(Self { http, api_url: api_url.trim_end_matches('/').to_string() })
    }

    async fn fetch_identity(&self, sso_session_id: &str) -> Result<Option<SsoIdentity>, SsoUnavailable> {
        // ID je overené is_valid_sso_id – do cesty URL sa vloží bez kódovania.
        let url = format!("{}/api/sessions/{sso_session_id}", self.api_url);
        let response = self.http.get(url).send().await.map_err(|e| SsoUnavailable(e.to_string()))?;
        if response.status() == StatusCode::NOT_FOUND {
            return Ok(None);
        }
        if !response.status().is_success() {
            return Err(SsoUnavailable(format!("SSO portál vrátil {}", response.status())));
        }
        let view: SessionView = response.json().await.map_err(|e| SsoUnavailable(e.to_string()))?;
        Ok(Some(SsoIdentity {
            sso_session_id: sso_session_id.to_string(),
            operator: view.operator,
            customer: view.customer,
        }))
    }
}

impl SsoApi for SsoClient {
    fn fetch<'a>(&'a self, sso_session_id: &'a str) -> BoxFuture<'a, Result<Option<SsoIdentity>, SsoUnavailable>> {
        Box::pin(self.fetch_identity(sso_session_id))
    }
}
```

```rust
//! Úložisko zdieľanej session (Redis hash `crm:session:{SSO_ID}`, hodnoty sú JSON reťazce) – Java
//! `SharedSessionStore`. Kontrakt medzi appkami tvorí len názov hashu, polia a JSON tvar hodnôt.

use std::collections::HashMap;
use std::fmt;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Mutex, MutexGuard, PoisonError};
use std::time::Duration;

use redis::aio::MultiplexedConnection;

use crate::BoxFuture;

const KEY_PREFIX: &str = "crm:session:";
const FLAG_KEY: &str = "crm:flags:session-read-source";
const TTL_SECONDS: i64 = 30 * 60;
/// Ako Java `spring.data.redis.timeout=500ms`: pri výpadku stránka zlyhá rýchlo a beží ďalej bez session.
const TIMEOUT: Duration = Duration::from_millis(500);

/// Chyba úložiska (výpadok, timeout) – volajúci ju zaloguje a pokračuje bez zdieľanej session.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StoreError(pub String);

impl fmt::Display for StoreError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "zdieľaná session: {}", self.0)
    }
}

impl std::error::Error for StoreError {}

/// Port na zdieľanú session všetkých appiek.
pub trait SharedSessionStore: Send + Sync {
    /// JSON hodnota poľa; obnoví TTL hashu.
    fn get_json<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<Option<String>, StoreError>>;
    /// Zapíše JSON hodnotu poľa; obnoví TTL hashu.
    fn put_json<'a>(&'a self, sso_id: &'a str, key: &'a str, json: String) -> BoxFuture<'a, Result<(), StoreError>>;
    /// Odstráni pole.
    fn remove<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<(), StoreError>>;
    /// Flag zdroja čítania starej appky – Rust appka ho len zobrazuje.
    fn legacy_read_source(&self) -> BoxFuture<'_, Result<Option<String>, StoreError>>;
}

fn lock<T>(mutex: &Mutex<T>) -> MutexGuard<'_, T> {
    mutex.lock().unwrap_or_else(PoisonError::into_inner)
}

/// In-memory úložisko pre testy (Java `InMemorySharedSessionStore`), vie simulovať výpadok.
#[derive(Default)]
pub struct InMemorySharedSessionStore {
    hashes: Mutex<HashMap<String, HashMap<String, String>>>,
    legacy_flag: Mutex<Option<String>>,
    failing: AtomicBool,
}

impl InMemorySharedSessionStore {
    /// Zapne/vypne simulovaný výpadok (všetky operácie vrátia chybu).
    pub fn set_failing(&self, failing: bool) {
        self.failing.store(failing, Ordering::SeqCst);
    }

    /// Nastaví flag starej appky.
    pub fn set_legacy_flag(&self, value: Option<&str>) {
        *lock(&self.legacy_flag) = value.map(String::from);
    }

    /// Surová hodnota poľa (overenie JSON v testoch).
    pub fn field(&self, sso_id: &str, key: &str) -> Option<String> {
        lock(&self.hashes).get(sso_id)?.get(key).cloned()
    }

    /// Zapíše pole priamo – simuluje zápis inej appky.
    pub fn put_field(&self, sso_id: &str, key: &str, json: &str) {
        lock(&self.hashes).entry(sso_id.to_string()).or_default().insert(key.to_string(), json.to_string());
    }

    fn check(&self) -> Result<(), StoreError> {
        if self.failing.load(Ordering::SeqCst) {
            return Err(StoreError("simulovaný výpadok".to_string()));
        }
        Ok(())
    }
}

impl SharedSessionStore for InMemorySharedSessionStore {
    fn get_json<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<Option<String>, StoreError>> {
        Box::pin(async move {
            self.check()?;
            Ok(self.field(sso_id, key))
        })
    }

    fn put_json<'a>(&'a self, sso_id: &'a str, key: &'a str, json: String) -> BoxFuture<'a, Result<(), StoreError>> {
        Box::pin(async move {
            self.check()?;
            self.put_field(sso_id, key, &json);
            Ok(())
        })
    }

    fn remove<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<(), StoreError>> {
        Box::pin(async move {
            self.check()?;
            if let Some(hash) = lock(&self.hashes).get_mut(sso_id) {
                hash.remove(key);
            }
            Ok(())
        })
    }

    fn legacy_read_source(&self) -> BoxFuture<'_, Result<Option<String>, StoreError>> {
        Box::pin(async move {
            self.check()?;
            Ok(lock(&self.legacy_flag).clone())
        })
    }
}

/// Redis implementácia – rovnaké kľúče a TTL ako Java (`StringRedisTemplate`) aj stará appka (Jedis).
pub struct RedisSharedSessionStore {
    client: redis::Client,
    connection: tokio::sync::Mutex<Option<MultiplexedConnection>>,
}

impl RedisSharedSessionStore {
    /// Klient bez pripojenia – appka naštartuje aj bez Redisu, spojí sa pri prvom použití.
    pub fn new(url: &str) -> Result<Self, StoreError> {
        let client = redis::Client::open(url).map_err(|e| StoreError(e.to_string()))?;
        Ok(Self { client, connection: tokio::sync::Mutex::new(None) })
    }

    /// Pipeline s timeoutom. Po chybe sa spojenie zahodí, aby sa po reštarte Redisu vytvorilo nové –
    /// multiplexované spojenie by inak ostalo mŕtve a appka by zdieľanú session už nikdy nevidela.
    async fn query<T: redis::FromRedisValue>(&self, pipeline: redis::Pipeline) -> Result<T, StoreError> {
        let attempt = async {
            let mut connection = self.connection().await?;
            pipeline.query_async::<T>(&mut connection).await.map_err(|e| StoreError(e.to_string()))
        };
        let result = tokio::time::timeout(TIMEOUT, attempt)
            .await
            .unwrap_or_else(|_| Err(StoreError("timeout".to_string())));
        if result.is_err() {
            *self.connection.lock().await = None;
        }
        result
    }

    async fn connection(&self) -> Result<MultiplexedConnection, StoreError> {
        let mut guard = self.connection.lock().await;
        if let Some(connection) = guard.as_ref() {
            return Ok(connection.clone());
        }
        let connection = self.client.get_multiplexed_async_connection().await
            .map_err(|e| StoreError(e.to_string()))?;
        *guard = Some(connection.clone());
        Ok(connection)
    }
}

impl SharedSessionStore for RedisSharedSessionStore {
    fn get_json<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<Option<String>, StoreError>> {
        Box::pin(async move {
            let hash = format!("{KEY_PREFIX}{sso_id}");
            let mut pipeline = redis::pipe();
            pipeline.cmd("HGET").arg(&hash).arg(key).cmd("EXPIRE").arg(&hash).arg(TTL_SECONDS).ignore();
            let (value,): (Option<String>,) = self.query(pipeline).await?;
            Ok(value)
        })
    }

    fn put_json<'a>(&'a self, sso_id: &'a str, key: &'a str, json: String) -> BoxFuture<'a, Result<(), StoreError>> {
        Box::pin(async move {
            let hash = format!("{KEY_PREFIX}{sso_id}");
            let mut pipeline = redis::pipe();
            pipeline.cmd("HSET").arg(&hash).arg(key).arg(json).ignore()
                .cmd("EXPIRE").arg(&hash).arg(TTL_SECONDS).ignore();
            self.query::<()>(pipeline).await
        })
    }

    fn remove<'a>(&'a self, sso_id: &'a str, key: &'a str) -> BoxFuture<'a, Result<(), StoreError>> {
        Box::pin(async move {
            let mut pipeline = redis::pipe();
            pipeline.cmd("HDEL").arg(format!("{KEY_PREFIX}{sso_id}")).arg(key).ignore();
            self.query::<()>(pipeline).await
        })
    }

    fn legacy_read_source(&self) -> BoxFuture<'_, Result<Option<String>, StoreError>> {
        Box::pin(async move {
            let mut pipeline = redis::pipe();
            pipeline.cmd("GET").arg(FLAG_KEY);
            let (value,): (Option<String>,) = self.query(pipeline).await?;
            Ok(value)
        })
    }
}
```

```rust
//! Lokálna (nezdieľaná) session Rust appky – náhrada `HttpSession` Java verzie, drží kritériá vyhľadávania
//! (`@SessionAttributes`). Vlastná cookie s cestou /crm-rs, aby sa za jedným nginx nebila s Java ani Liferay.

use std::any::Any;
use std::collections::HashMap;
use std::sync::{Mutex, MutexGuard, PoisonError};
use std::time::{Duration, Instant};

use uuid::Uuid;

use crate::CONTEXT_PATH;

/// Cookie lokálnej session (Java: `CRM_SESSION`, Path=/crm).
pub const COOKIE: &str = "CRM_RS_SESSION";
/// Ako predvolený timeout HttpSession (30 min nečinnosti).
const IDLE_TIMEOUT: Duration = Duration::from_secs(30 * 60);

type Attributes = HashMap<&'static str, Box<dyn Any + Send + Sync>>;

struct Entry {
    attributes: Attributes,
    last_access: Instant,
}

/// Lokálne session v pamäti procesu (jedna inštancia appky – ako HttpSession bez replikácie v Jave).
#[derive(Default)]
pub struct LocalSessions {
    entries: Mutex<HashMap<String, Entry>>,
}

impl LocalSessions {
    /// Hodnota kľúča v session `id`; neznáma/expirovaná session alebo iný typ = prázdno.
    pub fn get<T: Clone + 'static>(&self, id: Option<&str>, key: &'static str) -> Option<T> {
        let mut entries = self.lock();
        let entry = entries.get_mut(id?)?;
        if entry.last_access.elapsed() >= IDLE_TIMEOUT {
            return None;
        }
        entry.last_access = Instant::now();
        entry.attributes.get(key)?.downcast_ref::<T>().cloned()
    }

    /// Uloží hodnotu; ak session ešte nie je, založí ju a vráti jej ID pre Set-Cookie (Java `getSession(true)`).
    pub fn put<T: Send + Sync + 'static>(&self, id: Option<&str>, key: &'static str, value: T) -> Option<String> {
        let mut entries = self.lock();
        entries.retain(|_, entry| entry.last_access.elapsed() < IDLE_TIMEOUT);
        if let Some(entry) = id.and_then(|id| entries.get_mut(id)) {
            entry.attributes.insert(key, Box::new(value));
            entry.last_access = Instant::now();
            return None;
        }
        let new_id = Uuid::new_v4().to_string();
        let mut attributes = Attributes::new();
        attributes.insert(key, Box::new(value));
        entries.insert(new_id.clone(), Entry { attributes, last_access: Instant::now() });
        Some(new_id)
    }

    /// Odstráni kľúč (Java `SessionStatus.setComplete()` pre `@SessionAttributes`).
    pub fn remove(&self, id: Option<&str>, key: &'static str) {
        let Some(id) = id else { return };
        if let Some(entry) = self.lock().get_mut(id) {
            entry.attributes.remove(key);
        }
    }

    fn lock(&self) -> MutexGuard<'_, HashMap<String, Entry>> {
        self.entries.lock().unwrap_or_else(PoisonError::into_inner)
    }
}

/// Hodnota hlavičky Set-Cookie pre novú session.
pub fn set_cookie_value(id: &str) -> String {
    format!("{COOKIE}={id}; Path={CONTEXT_PATH}; HttpOnly; SameSite=Lax")
}
```

```rust
//! Doména blacklistu ne-zákazníka – rovnaké pojmy a hodnoty ako Java verzia (vymyslené, zjednodušené).

use std::sync::LazyLock;

use chrono::{NaiveDate, NaiveDateTime};
use regex::Regex;

named_enum!(BlacklistState { Active => "ACTIVE", Inactive => "INACTIVE" });

named_enum!(
    /// Dôvod zaradenia na blacklist.
    StateReason { Fraud => "FRAUD", Debt => "DEBT", Abuse => "ABUSE" }
);

named_enum!(
    /// Podmienka, ktorá sa uplatní pri objednávke osoby z blacklistu.
    ConditionType { BlockAll => "BLOCK_ALL", RequireDeposit => "REQUIRE_DEPOSIT", ManualApproval => "MANUAL_APPROVAL" }
);

named_enum!(
    /// Typ identifikátora osoby.
    IdentifierType {
        BirthCode => "BIRTH_CODE",
        IdCard => "ID_CARD",
        Passport => "PASSPORT",
        CompanyRegNo => "COMPANY_REG_NO",
    }
);

impl IdentifierType {
    /// Formát hodnoty ako Java regex (`matches()` = celý reťazec); `[0-9]`, lebo Rust `\d` berie aj Unicode číslice.
    pub fn is_valid(self, value: &str) -> bool {
        static FORMATS: LazyLock<[Regex; 4]> = LazyLock::new(|| {
            [r"^[0-9]{6}/?[0-9]{3,4}$", r"^[A-Z]{2}[0-9]{6}$", r"^[A-Z][0-9]{7}$", r"^[0-9]{8}$"]
                .map(|pattern| Regex::new(pattern).expect("platný regex"))
        });
        let index = match self {
            IdentifierType::BirthCode => 0,
            IdentifierType::IdCard => 1,
            IdentifierType::Passport => 2,
            IdentifierType::CompanyRegNo => 3,
        };
        FORMATS[index].is_match(value)
    }
}

/// Identifikátor osoby (`kind`, lebo `type` je v Ruste kľúčové slovo).
```

```rust
//! Port na backend blacklistu + in-memory náhrada (vymyslené dáta, seed zhodný s Java appkou). Reálna migrácia
//! sem pripojí adaptér na existujúci backend – handlery sa nemenia.

use std::collections::BTreeMap;
use std::sync::{Arc, Mutex, MutexGuard, PoisonError};

use chrono::{NaiveDate, NaiveDateTime, Timelike};

use crate::blacklist::model::{
    BlacklistRecord, BlacklistState, ConditionType, Identifier, IdentifierType, NewBlacklistRecord, Note,
    SearchCriteria, StateReason,
};
use crate::clock::Clock;

/// Chyba backendu – web vrstva z `NotFound` spraví 404, `Rule` nesie i18n kľúč hlášky.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum BlacklistError {
    NotFound(String),
    Rule(&'static str),
}

/// Port na backend blacklistu (Java `BlacklistService`).
pub trait BlacklistService: Send + Sync {
    /// Záznamy podľa kritérií v poradí ID.
    fn search(&self, criteria: &SearchCriteria) -> Vec<BlacklistRecord>;
    /// Záznam podľa ID.
    fn find_by_id(&self, id: u64) -> Option<BlacklistRecord>;
    /// Vytvorí aktívny záznam s jedným identifikátorom.
    fn create(&self, data: NewBlacklistRecord) -> BlacklistRecord;
    /// Zmena stavu a platnosti; deaktivácia bez „platné do“ doplní dnešný dátum.
    fn change(&self, id: u64, state: BlacklistState, valid_to: Option<NaiveDate>) -> Result<(), BlacklistError>;
    /// Pridá poznámku (text sa oreže, čas na minúty).
    fn add_note(&self, id: u64, text: &str, author: &str) -> Result<(), BlacklistError>;
    /// Vráti zostávajúce identifikátory; posledný sa odstrániť nedá.
    fn remove_identifier(&self, record_id: u64, identifier_id: u64) -> Result<Vec<Identifier>, BlacklistError>;
    /// Povolené podmienky pre dôvod; `None` = všetky.
    fn allowed_condition_types(&self, reason: Option<StateReason>) -> Vec<ConditionType>;
}

struct Inner {
    records: BTreeMap<u64, BlacklistRecord>,
    next_record_id: u64,
    next_identifier_id: u64,
}

/// In-memory backend. Mutex – jednoduchosť pred výkonom (Java `synchronized`); reálny backend má transakcie.
pub struct InMemoryBlacklistService {
    clock: Arc<dyn Clock>,
    inner: Mutex<Inner>,
}

impl InMemoryBlacklistService {
    /// Služba so seed dátami.
    pub fn new(clock: Arc<dyn Clock>) -> Self {
        let mut inner = Inner { records: BTreeMap::new(), next_record_id: 1, next_identifier_id: 1 };
        seed(&mut inner);
        Self { clock, inner: Mutex::new(inner) }
    }

    fn lock(&self) -> MutexGuard<'_, Inner> {
        self.inner.lock().unwrap_or_else(PoisonError::into_inner)
    }
}

impl Inner {
    fn add(&mut self, name: (&str, &str), birth_date: NaiveDate, state: BlacklistState,
           rule: (StateReason, ConditionType), validity: (NaiveDate, Option<NaiveDate>)) -> u64 {
        let id = self.next_record_id;
        self.next_record_id += 1;
        self.records.insert(id, BlacklistRecord {
            id,
            first_name: name.0.to_string(),
            last_name: name.1.to_string(),
            birth_date,
            state,
            state_reason: rule.0,
            condition_type: rule.1,
            valid_from: validity.0,
            valid_to: validity.1,
            identifiers: Vec::new(),
            notes: Vec::new(),
        });
        id
    }

    fn identifier(&mut self, record_id: u64, kind: IdentifierType, value: &str) {
        let id = self.next_identifier_id;
        self.next_identifier_id += 1;
        if let Some(record) = self.records.get_mut(&record_id) {
            record.identifiers.push(Identifier { id, kind, value: value.to_string() });
        }
    }

    fn require(&mut self, id: u64) -> Result<&mut BlacklistRecord, BlacklistError> {
        self.records.get_mut(&id).ok_or_else(|| BlacklistError::NotFound(format!("záznam blacklistu {id}")))
    }
}

impl BlacklistService for InMemoryBlacklistService {
    fn search(&self, criteria: &SearchCriteria) -> Vec<BlacklistRecord> {
        self.lock().records.values().filter(|r| matches(r, criteria)).cloned().collect()
    }

    fn find_by_id(&self, id: u64) -> Option<BlacklistRecord> {
        self.lock().records.get(&id).cloned()
    }

    fn create(&self, data: NewBlacklistRecord) -> BlacklistRecord {
        let mut inner = self.lock();
        let id = inner.add((&data.first_name, &data.last_name), data.birth_date, BlacklistState::Active,
            (data.state_reason, data.condition_type), (data.valid_from, data.valid_to));
        inner.identifier(id, data.identifier_type, &data.identifier_value);
        inner.records[&id].clone()
    }

    fn change(&self, id: u64, state: BlacklistState, valid_to: Option<NaiveDate>) -> Result<(), BlacklistError> {
        let effective = match (state, valid_to) {
            (BlacklistState::Inactive, None) => Some(self.clock.today()),
            _ => valid_to,
        };
        let mut inner = self.lock();
        let record = inner.require(id)?;
        record.state = state;
        record.valid_to = effective;
        Ok(())
    }

    fn add_note(&self, id: u64, text: &str, author: &str) -> Result<(), BlacklistError> {
        let now = self.clock.now();
        let created_at = now.with_second(0).and_then(|t| t.with_nanosecond(0)).unwrap_or(now);
        let note = Note { text: text.trim().to_string(), author: author.to_string(), created_at };
        self.lock().require(id)?.notes.push(note);
        Ok(())
    }

    fn remove_identifier(&self, record_id: u64, identifier_id: u64) -> Result<Vec<Identifier>, BlacklistError> {
        let mut inner = self.lock();
        let record = inner.require(record_id)?;
        // Identifikátor iného záznamu = podvrhnuté ID → 404, nie zmena cudzích dát.
        let Some(position) = record.identifiers.iter().position(|i| i.id == identifier_id) else {
            return Err(BlacklistError::NotFound(format!("identifikátor {identifier_id} záznamu {record_id}")));
        };
        if record.identifiers.len() == 1 {
            return Err(BlacklistError::Rule("blacklist.detail.lastIdentifier"));
        }
        record.identifiers.remove(position);
        Ok(record.identifiers.clone())
    }

    fn allowed_condition_types(&self, reason: Option<StateReason>) -> Vec<ConditionType> {
        match reason {
            None => ConditionType::ALL.to_vec(),
            Some(StateReason::Fraud) => vec![ConditionType::BlockAll],
            Some(StateReason::Debt) => vec![ConditionType::RequireDeposit, ConditionType::ManualApproval],
            Some(StateReason::Abuse) => vec![ConditionType::ManualApproval, ConditionType::BlockAll],
        }
    }
}

fn matches(record: &BlacklistRecord, criteria: &SearchCriteria) -> bool {
    let identifier = non_blank(criteria.identifier_value.as_deref());
    contains_ignore_case(&record.first_name, criteria.first_name.as_deref())
        && contains_ignore_case(&record.last_name, criteria.last_name.as_deref())
        && identifier.is_none_or(|v| record.identifiers.iter().any(|i| i.value.to_lowercase() == v.to_lowercase()))
        && criteria.state.is_none_or(|state| state == record.state)
}

fn non_blank(value: Option<&str>) -> Option<&str> {
    value.map(str::trim).filter(|v| !v.is_empty())
}

fn contains_ignore_case(value: &str, query: Option<&str>) -> bool {
    non_blank(query).is_none_or(|q| value.to_lowercase().contains(&q.to_lowercase()))
}

fn date(year: i32, month: u32, day: u32) -> NaiveDate {

}

fn at(day: NaiveDate, hour: u32) -> NaiveDateTime {
    day.and_hms_opt(hour, 0, 0).expect("platný čas v seed dátach")
}
```

```rust
/// Hodnota sa nedá previesť na dátum/enum.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct InvalidValue;

fn non_blank(raw: &Option<String>) -> Option<&str> {
    raw.as_deref().map(str::trim).filter(|v| !v.is_empty())
}

fn text(raw: &Option<String>) -> &str {
    raw.as_deref().unwrap_or("")
}

/// Enum z Java mena; prázdne = nevyplnené (Spring prázdny reťazec naviaže ako null).
pub fn parse_enum<T>(raw: &Option<String>, from_name: fn(&str) -> Option<T>) -> Result<Option<T>, InvalidValue> {
    non_blank(raw).map(|v| from_name(v).ok_or(InvalidValue)).transpose()
}

/// ISO dátum (`<input type="date">`); prázdne = nevyplnené.
pub fn parse_date(raw: &Option<String>) -> Result<Option<NaiveDate>, InvalidValue> {
    non_blank(raw).map(|v| NaiveDate::parse_from_str(v, "%Y-%m-%d").map_err(|_| InvalidValue)).transpose()
}

fn required<T>(parsed: Result<Option<T>, InvalidValue>, path: &'static str, out: &mut Vec<Violation>) -> Option<T> {
    match parsed {
        Ok(Some(value)) => Some(value),
        Ok(None) => {
            out.push(Violation::new(path, REQUIRED));
            None
        }
        Err(InvalidValue) => {
            out.push(Violation::new(path, INVALID));
            None
        }
    }
}

fn optional<T>(parsed: Result<Option<T>, InvalidValue>, path: &'static str, out: &mut Vec<Violation>) -> Option<T> {
    parsed.unwrap_or_else(|InvalidValue| {
        out.push(Violation::new(path, INVALID));
        None
    })
}

fn required_text(raw: &Option<String>, path: &'static str, out: &mut Vec<Violation>) -> Option<String> {
    required(Ok(non_blank(raw).map(String::from)), path, out)
}

    pub last_name: Option<String>,

    pub state: Option<String>,

impl SearchForm {
    /// Odoslané polia prepíšu kritériá zo session, neodoslané ostanú (binding na objekt zo session).
    pub fn merge(self, posted: SearchForm) -> SearchForm {
        SearchForm {
            first_name: posted.first_name.or(self.first_name),
            last_name: posted.last_name.or(self.last_name),
            identifier_value: posted.identifier_value.or(self.identifier_value),
            state: posted.state.or(self.state),
        }
    }

    /// Aspoň jedno kritérium (medzery sa nerátajú) a platný stav.
    pub fn validate(&self) -> Result<SearchCriteria, Vec<Violation>> {
        let state = parse_enum(&self.state, BlacklistState::from_name)
            .map_err(|_| vec![Violation::new("state", INVALID)])?;
        let any = [&self.first_name, &self.last_name, &self.identifier_value].into_iter().any(|v| non_blank(v).is_some());
        if !any && state.is_none() {

    pub fn validate(&self, today: NaiveDate, allowed: impl Fn(Option<StateReason>) -> Vec<ConditionType>)
        -> Result<NewBlacklistRecord, Vec<Violation>> {
        let mut out = Vec::new();
        let first_name = required_text(&self.first_name, "firstName", &mut out);
        let last_name = required_text(&self.last_name, "lastName", &mut out);
        let birth_date = required(parse_date(&self.birth_date), "birthDate", &mut out);
        if birth_date.is_some_and(|d| d >= today) {
            out.push(Violation::new("birthDate", "validation.past"));
        }
        let state_reason = required(parse_enum(&self.state_reason, StateReason::from_name), "stateReason", &mut out);
        let condition_type = required(parse_enum(&self.condition_type, ConditionType::from_name), "conditionType", &mut out);
        let valid_from = required(parse_date(&self.valid_from), "validFrom", &mut out);
        let valid_to = optional(parse_date(&self.valid_to), "validTo", &mut out);
        let identifier_type = required(parse_enum(&self.identifier_type, IdentifierType::from_name), "identifierType", &mut out);
        let identifier_value = required_text(&self.identifier_value, "identifierValue", &mut out);
        cross_field_rules(&mut out, (valid_from, valid_to), (identifier_type, identifier_value.as_deref()),
            (state_reason, condition_type), allowed);
        match (first_name, last_name, birth_date, state_reason, condition_type, valid_from, identifier_type, identifier_value) {
            (Some(first_name), Some(last_name), Some(birth_date), Some(state_reason), Some(condition_type),
             Some(valid_from), Some(identifier_type), Some(identifier_value)) if out.is_empty() => Ok(NewBlacklistRecord {
                first_name, last_name, birth_date, state_reason, condition_type, valid_from, valid_to,
                identifier_type, identifier_value,
            }),
            _ => Err(out),
        }
    }

            "validFrom" => text(&self.valid_from),
            "validTo" => text(&self.valid_to),
            "identifierType" => text(&self.identifier_type),
            "identifierValue" => text(&self.identifier_value),
            _ => "",
        }
    }

/// Java `@AssertTrue isPeriodValid/isIdentifierValid` + pravidlo backendu o povolených podmienkach.
fn cross_field_rules(out: &mut Vec<Violation>, period: (Option<NaiveDate>, Option<NaiveDate>),
                     identifier: (Option<IdentifierType>, Option<&str>),
                     rule: (Option<StateReason>, Option<ConditionType>),
                     allowed: impl Fn(Option<StateReason>) -> Vec<ConditionType>) {
    if let (Some(from), Some(to)) = period {
        if to < from {
            out.push(Violation::new("periodValid", "blacklist.create.periodInvalid"));
        }
    }
    if let (Some(kind), Some(value)) = identifier {
        if !kind.is_valid(value) {
            out.push(Violation::new("identifierValid", "blacklist.create.identifierInvalid"));
        }
    }
    if let (Some(reason), Some(condition)) = rule {
        if !allowed(Some(reason)).contains(&condition) {
            out.push(Violation::new("conditionType", "blacklist.create.conditionNotAllowed"));
        }
    }
}
```

```rust
//! `Tags` = JSP taglib `portal:*` a `common:*` s rovnakým „rozhraním“ (mená, parametre), volaný zo šablón.
//! URL sa skladajú konvenciou `{ctx}{base}/{segment}?parametre` ako Java `PortletUrlTag`. Segment je
//! `&'static str` – v šablóne len literál, takže podvrhnutý segment sa nedá ani skompilovať (Java to kontroluje za behu).

use std::collections::HashSet;
use std::fmt::{self, Display};
use std::sync::Arc;

use crate::CONTEXT_PATH;
use crate::acl::Privilege;
use crate::blacklist::forms::Violation;
use crate::web::messages::Messages;

/// Base path „portletu“ blacklist (Java `@LegacyPortlet("/blacklist")`).
pub const PORTLET_BASE: &str = "/blacklist";

/// Plná cesta v rámci portletu, napr. `/search` → `/crm-rs/blacklist/search`.
pub fn portlet_path(path: &str) -> String {
    format!("{CONTEXT_PATH}{PORTLET_BASE}{path}")
}

/// URL kódovanie ako Java `URLEncoder.encode(…, UTF_8)`.
pub fn encode(value: &str) -> String {
    form_urlencoded::byte_serialize(value.as_bytes()).collect()
}

/// HTML escape textu (Spring `HtmlUtils.htmlEscape`).
pub fn escape_html(value: &str) -> String {
    value.replace('&', "&amp;").replace('<', "&lt;").replace('>', "&gt;").replace('"', "&quot;").replace('\'', "&#39;")
}

/// Kontext tagov pre jednu stránku: texty a privilégiá prihláseného operátora.
#[derive(Debug, Clone)]
pub struct Tags {
    messages: Arc<Messages>,
    privileges: Arc<HashSet<Privilege>>,
    /// Context path pre odkazy na statické súbory a navigáciu (`${pageContext.request.contextPath}`).
    pub ctx: &'static str,
}

impl Tags {
    /// Tagy pre operátora s danými privilégiami (prázdne = neprihlásený).
    pub fn new(messages: Arc<Messages>, privileges: HashSet<Privilege>) -> Self {
        Self { messages, privileges: Arc::new(privileges), ctx: CONTEXT_PATH }
    }

    /// Texty (pre `FieldErrors::resolve`).
    pub fn messages(&self) -> &Messages {
        &self.messages
    }

    /// `<common:message key="…"/>`.
    pub fn msg(&self, key: &str) -> String {
        self.messages.get(key)
    }

    /// `<common:message key="prefix.${enum}"/>`.
    pub fn msg_of(&self, prefix: &str, name: &str) -> String {
        self.messages.get(&format!("{prefix}{name}"))
    }

    /// `<common:message key="…"><common:msgarg value="…"/></common:message>`.
    pub fn msg_with(&self, key: &str, arg: impl Display) -> String {
        self.messages.format(key, &[&arg])
    }

    /// `<common:aclFilter privilegeType="…">` – telo len s privilégiom.
    pub fn can(&self, privilege_type: &str) -> bool {
        match Privilege::from_name(privilege_type) {
            Some(privilege) => self.has(privilege),
            None => {
                tracing::error!("Neznáme privilégium v šablóne: {privilege_type}");
                false
            }
        }
    }

    /// Má operátor privilégium?
    pub fn has(&self, privilege: Privilege) -> bool {
        self.privileges.contains(&privilege)
    }

    /// `<common:aclPageFilterTag>` – druhá línia obrany za `Require<P>`; `None` = stránka bez filtra.
    pub fn page_allowed(&self, privilege_type: Option<&str>) -> bool {
        privilege_type.is_none_or(|p| self.can(p))
    }

    /// Text, ktorý page filter vypíše namiesto stránky.
    pub fn page_denied(&self, privilege_type: Option<&str>) -> String {
        self.messages.format("acl.pageDenied", &[&privilege_type.unwrap_or("")])
    }

    /// `<portal:renderURL>` s `render`/`viewPage` = segment (GET).
    pub fn render(&self, segment: &'static str) -> PortletUrl {
        PortletUrl::new(portlet_path(&format!("/{segment}")))
    }

    /// `<portal:actionURL>` s `action` = segment (POST).
    pub fn action(&self, segment: &'static str) -> PortletUrl {
        PortletUrl::new(portlet_path(&format!("/{segment}")))
    }

    /// `<portal:resourceURL id="…">` (AJAX) pod `{base}/resource/{id}`.
    pub fn resource(&self, id: &'static str) -> PortletUrl {
        PortletUrl::new(portlet_path(&format!("/resource/{id}")))
    }
}

/// URL „portletu“ s parametrami (`<portal:param>`); v šablóne ju escapuje askama (escapeXml=true).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PortletUrl {
    path: String,
    query: Vec<(String, String)>,
}

impl PortletUrl {
    fn new(path: String) -> Self {
        Self { path, query: Vec::new() }
    }

    /// `<portal:param name value>`.
    pub fn param(mut self, name: &str, value: impl Display) -> Self {
        self.query.push((name.to_string(), value.to_string()));
        self
    }
}

impl Display for PortletUrl {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.path)?;
        for (i, (name, value)) in self.query.iter().enumerate() {
            write!(f, "{}{}={}", if i == 0 { '?' } else { '&' }, encode(name), encode(value))?;
        }
        Ok(())
    }
}

/// Chyby formulára s preloženými textami (Spring `BindingResult` + `<form:errors>`).
#[derive(Debug, Clone, Default)]
pub struct FieldErrors {
    errors: Vec<(&'static str, String)>,
}

impl FieldErrors {
    /// Preloží porušené pravidlá na texty.
    pub fn resolve(violations: &[Violation], messages: &Messages) -> Self {
        Self { errors: violations.iter().map(|v| (v.path, messages.get(v.key))).collect() }
    }

    /// Bez chýb?
    pub fn is_empty(&self) -> bool {
        self.errors.is_empty()
    }

    /// `<form:errors path="…" cssClass="field-error"/>` – prázdne, ak pole nemá chybu.
    pub fn html(&self, path: &str) -> String {
        let texts: Vec<String> =
            self.errors.iter().filter(|(p, _)| *p == path).map(|(_, text)| escape_html(text)).collect();
        if texts.is_empty() {
            return String::new();
        }
        format!(r#"<span id="{path}.errors" class="field-error">{}</span>"#, texts.join("<br/>"))
    }

    /// `<form:errors path="*" cssClass="field-error" element="div"/>` – všetky chyby formulára `form_name`.
    pub fn all_html(&self, form_name: &str) -> String {
        if self.errors.is_empty() {
            return String::new();
        }
        let texts: Vec<String> = self.errors.iter().map(|(_, text)| escape_html(text)).collect();
        format!(r#"<div id="{form_name}.errors" class="field-error">{}</div>"#, texts.join("<br/>"))
    }
}
```

```rust
        Self { router: router.clone(), sso: sso.map(String::from), local: None }
    }

    pub async fn get(&mut self, path: &str) -> TestResponse {
        self.send(Method::GET, path, &[], Body::empty()).await
    }

    pub async fn post(&mut self, path: &str, form: &str) -> TestResponse {
        let headers = [("content-type", "application/x-www-form-urlencoded")];
        self.send(Method::POST, path, &headers, Body::from(form.to_string())).await
    }

    pub async fn ajax(&mut self, method: Method, path: &str) -> TestResponse {
        self.send(method, path, &[("x-requested-with", "XMLHttpRequest")], Body::empty()).await
    }

    async fn send(&mut self, method: Method, path: &str, headers: &[(&str, &str)], body: Body) -> TestResponse {
        let mut builder = Request::builder().method(method).uri(path);
        let cookies: Vec<String> = [self.sso.as_ref().map(|v| format!("SSO_ID={v}")),
            self.local.as_ref().map(|v| format!("CRM_RS_SESSION={v}"))].into_iter().flatten().collect();
        if !cookies.is_empty() {
            builder = builder.header(COOKIE, cookies.join("; "));
        }
        for (name, value) in headers {
            builder = builder.header(*name, *value);
        }
        let _ = CONTENT_TYPE;
        let response = self.router.clone().oneshot(builder.body(body).expect("request")).await.expect("odpoveď");
        let status = response.status();
        let headers = response.headers().clone();
        let bytes = response.into_body().collect().await.expect("telo").to_bytes();
        let result = TestResponse { status, headers, body: String::from_utf8_lossy(&bytes).into_owned() };
        if let Some(cookie) = result.set_cookie("CRM_RS_SESSION") {
            self.local = cookie.split(';').next().and_then(|c| c.split_once('=')).map(|(_, v)| v.to_string());
        }
        result
    }
```

```rust
//! Dáta hlavičky (Java `LayoutModel` – náhrada portletu „header“ z Liferay theme). Ploché reťazce a bool,
//! aby šablóna nepotrebovala `match` nad Option.

use crate::session::identity::SsoIdentity;
use crate::session::keys::{LastViewedRecord, UiMessage};
use crate::session::shared::CrmSession;
use crate::web::app::AppState;
use crate::web::tags::Tags;

/// Hlavička stránky.
#[derive(Debug, Clone, Default)]
pub struct LayoutModel {
    pub logged_in: bool,
    pub operator_name: String,
    pub customer_name: String,
    pub customer_id: String,
    pub has_last_viewed: bool,
    pub last_viewed_name: String,
    pub messages: Vec<UiMessage>,
    pub legacy_flag: String,
    pub sso_id_display: String,
}

impl LayoutModel {
    /// Hlášky sa tu vyberú (zobrazia sa raz) – volať len pri skutočnom vykreslení stránky, nie pri redirecte/AJAX.
    pub async fn build(identity: Option<&SsoIdentity>, session: &CrmSession) -> Self {
        let messages = session.pop_messages().await;
        let last_viewed = session.get::<LastViewedRecord>().await;
        let text = |f: fn(&SsoIdentity) -> &String| identity.map(|i| f(i).clone()).unwrap_or_default();
        Self {
            logged_in: identity.is_some(),
            operator_name: text(|i| &i.operator.display_name),
            customer_name: text(|i| &i.customer.display_name),
            customer_id: text(|i| &i.customer.customer_id),
            has_last_viewed: last_viewed.is_some(),
            last_viewed_name: last_viewed.map(|r| r.full_name).unwrap_or_default(),
            messages,
            legacy_flag: session.legacy_read_source().await.unwrap_or_else(|| "PORTLET".to_string()),
            sso_id_display: identity.map(|i| i.sso_session_id.clone()).unwrap_or_else(|| "-".to_string()),
        }
    }
}

/// Všetko, čo stránka s layoutom potrebuje okrem vlastných dát.
pub struct Page {
    pub tags: Tags,
    pub layout: LayoutModel,
}

impl Page {
    /// Tagy podľa privilégií operátora + hlavička zo zdieľanej session.
    pub async fn build(state: &AppState, identity: Option<&SsoIdentity>) -> Self {
        let privileges = identity.map(|i| state.acl.privileges_of(&i.operator)).unwrap_or_default();
        let session = CrmSession::new(identity.map(|i| i.sso_session_id.clone()), state.store.clone());
        Self {
            tags: Tags::new(state.messages.clone(), privileges),
            layout: LayoutModel::build(identity, &session).await,
        }
    }
}
```

```rust
//! Chyby a odpovede (Java `GlobalExceptionHandler` + chybové JSP). Chyba nesie už pripravenú stránku (`Page`),
//! lebo `IntoResponse` nemá prístup k stavu appky.

use askama::Template;
use axum::http::header::{LOCATION, SET_COOKIE};
use axum::http::{HeaderValue, StatusCode};
use axum::response::{Html, IntoResponse, Response};

use crate::acl::Privilege;

/// Obal chybovej odpovede: AJAX dostane fragment bez layoutu, stránka celý layout.
pub enum Shell {
    Fragment(Tags),
    Page(Page),
}

/// Chyba requestu.
pub enum AppError {
    /// Bez SSO identity: stránka → SSO login, AJAX → 401.
    LoginRequired { ajax: bool, login_url: String },
    SsoUnavailable(Page),
    AclDenied { privilege: Privilege, shell: Shell },
    NotFound(Page),
    /// Zlý parameter (Java 400 cez Boot error page); `None` = AJAX.
    BadRequest(Option<Page>),
    Internal,
}

#[derive(Template)]
#[template(path = "error/403.html")]
struct ForbiddenPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    privilege: &'static str,
}

#[derive(Template)]
#[template(path = "error/403-fragment.html")]
struct ForbiddenFragment {
    tags: Tags,
    privilege: &'static str,
}

#[derive(Template)]
#[template(path = "error/404.html")]
struct NotFoundPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
}

#[derive(Template)]
#[template(path = "error/sso.html")]
struct SsoErrorPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
}

#[derive(Template)]
#[template(path = "error/error.html")]
struct GenericErrorPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    status: u16,
    error: &'static str,
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        match self {
            AppError::LoginRequired { ajax: true, .. } => StatusCode::UNAUTHORIZED.into_response(),
            AppError::LoginRequired { ajax: false, login_url } => redirect(&login_url),
            AppError::SsoUnavailable(Page { tags, layout }) => with_status(StatusCode::SERVICE_UNAVAILABLE,
                html(&SsoErrorPage { tags, layout, title_key: "error.generic.title", privilege_filter: None })),
            AppError::AclDenied { privilege, shell: Shell::Fragment(tags) } =>
                with_status(StatusCode::FORBIDDEN, html(&ForbiddenFragment { tags, privilege: privilege.name() })),
            AppError::AclDenied { privilege, shell: Shell::Page(Page { tags, layout }) } => with_status(StatusCode::FORBIDDEN,
                html(&ForbiddenPage { tags, layout, title_key: "error.403.title", privilege_filter: None, privilege: privilege.name() })),
            AppError::NotFound(Page { tags, layout }) => with_status(StatusCode::NOT_FOUND,
                html(&NotFoundPage { tags, layout, title_key: "error.404.title", privilege_filter: None })),
            AppError::BadRequest(Some(Page { tags, layout })) => with_status(StatusCode::BAD_REQUEST,
                html(&GenericErrorPage { tags, layout, title_key: "error.generic.title", privilege_filter: None,
                    status: 400, error: "Bad Request" })),
            AppError::BadRequest(None) => StatusCode::BAD_REQUEST.into_response(),
            AppError::Internal => internal_error(),
        }
    }
}

fn internal_error() -> Response {
    (StatusCode::INTERNAL_SERVER_ERROR, "Interná chyba – podrobnosti sú v logu.").into_response()
}

/// Vykreslí šablónu ako HTML; chyba šablóny = 500 + log.
pub fn html<T: Template>(template: &T) -> Response {
    match template.render() {
        Ok(body) => Html(body).into_response(),
        Err(e) => {
            tracing::error!("Vykreslenie šablóny zlyhalo: {e}");
            internal_error()
        }
    }
}

/// Nastaví stav odpovede, ak sa vykreslenie podarilo (500 z `html` ostáva).
pub fn with_status(status: StatusCode, mut response: Response) -> Response {
    if response.status().is_success() {
        *response.status_mut() = status;
    }
    response
}

/// 302 ako Spring `redirect:` (axum `Redirect::to` dáva 303).
pub fn redirect(location: &str) -> Response {
    (StatusCode::FOUND, [(LOCATION, location.to_string())]).into_response()
}

/// Pridá Set-Cookie novej lokálnej session.
pub fn with_cookie(mut response: Response, new_session_id: Option<String>) -> Response {
    if let Some(value) = new_session_id.and_then(|id| HeaderValue::from_str(&set_cookie_value(&id)).ok()) {
        response.headers_mut().append(SET_COOKIE, value);
    }
    response
}
```

```rust
//! „Portlet“ = skupina handlerov so spoločným base path. Extraktory robia to, čo Java `LegacyPortletInterceptor`:
//! bez identity zo SSO nepustia ďalej (stránka → SSO login, AJAX → 401) a skontrolujú privilégium. Privilégium je
//! typ v signatúre handlera (`Require<Modify>`), takže sa nedá zabudnúť ako anotácia.

use std::marker::PhantomData;

use axum::extract::FromRequestParts;
use axum::http::request::Parts;
use axum::http::{HeaderMap, Method};
use axum::response::Response;

use crate::CONTEXT_PATH;
use crate::acl::Privilege;
use crate::session::identity::{SSO_COOKIE, SsoIdentity, SsoUnavailable, is_valid_sso_id};
use crate::session::local;
use crate::session::shared::CrmSession;
use crate::web::app::AppState;
use crate::web::errors::{AppError, Shell, redirect};
use crate::web::layout::Page;
use crate::web::requests::{cookie, is_ajax};
use crate::web::tags::{PORTLET_BASE, Tags, encode, portlet_path};

/// Kontext prihláseného operátora pre jeden request (identita sa zo SSO pýta raz).
pub struct Ctx {
    pub state: AppState,
    pub identity: SsoIdentity,
    pub session: CrmSession,
    pub local_session_id: Option<String>,
    pub ajax: bool,
    pub tags: Tags,
}

/// Identita podľa cookie SSO_ID; neplatný tvar = neprihlásený bez volania SSO.
pub async fn resolve_identity(headers: &HeaderMap, state: &AppState) -> Result<Option<SsoIdentity>, SsoUnavailable> {
    match cookie(headers, SSO_COOKIE).filter(|value| is_valid_sso_id(value)) {
        Some(sso_id) => state.sso.fetch(&sso_id).await,
        None => Ok(None),
    }
}

/// SSO login s návratom na `return_path` (Java `SsoIdentityResolver.loginUrl`).
pub fn login_url(sso_login_url: &str, return_path: &str) -> String {
    format!("{sso_login_url}?returnUrl={}", encode(return_path))
}

/// Kam sa vrátiť po prihlásení: GET na tú istú adresu, inak na stránku portletu (POST URL by po návrate dala 405).
fn return_path(parts: &Parts) -> String {
    if parts.method != Method::GET {
        return format!("{CONTEXT_PATH}{PORTLET_BASE}");
    }
    parts.uri.path_and_query().map(|pq| pq.as_str().to_string()).unwrap_or_else(|| parts.uri.path().to_string())
}

impl FromRequestParts<AppState> for Ctx {
    type Rejection = AppError;

    async fn from_request_parts(parts: &mut Parts, state: &AppState) -> Result<Self, AppError> {
        let ajax = is_ajax(&parts.headers);
        let identity = match resolve_identity(&parts.headers, state).await {
            Ok(identity) => identity,
            Err(e) => {
                tracing::error!("{e}");
                return Err(AppError::SsoUnavailable(Page::build(state, None).await));
            }
        };
        let Some(identity) = identity else {
            let login_url = login_url(&state.config.sso_login_url, &return_path(parts));
            return Err(AppError::LoginRequired { ajax, login_url });
        };
        Ok(Ctx {
            session: CrmSession::new(Some(identity.sso_session_id.clone()), state.store.clone()),
            local_session_id: cookie(&parts.headers, local::COOKIE),
            tags: Tags::new(state.messages.clone(), state.acl.privileges_of(&identity.operator)),
            identity,
            ajax,
            state: state.clone(),
        })
    }
}

/// Privilégium vyžadované handlerom (Java `@RequiresPrivilege`).
pub trait RequiredPrivilege {
    const PRIVILEGE: Privilege;
}

/// Prezeranie blacklistu.
pub struct View;
/// Zmeny v blackliste.
pub struct Modify;

impl RequiredPrivilege for View {
    const PRIVILEGE: Privilege = Privilege::BlacklistView;
}

impl RequiredPrivilege for Modify {
    const PRIVILEGE: Privilege = Privilege::BlacklistModify;
}

/// Prihlásený operátor s privilégiom `P`; inak 403 (stránka alebo AJAX fragment).
pub struct Require<P>(pub Ctx, pub PhantomData<P>);

impl<P: RequiredPrivilege + Send + Sync> FromRequestParts<AppState> for Require<P> {
    type Rejection = AppError;

    async fn from_request_parts(parts: &mut Parts, state: &AppState) -> Result<Self, AppError> {
        let ctx = Ctx::from_request_parts(parts, state).await?;
        if !ctx.tags.has(P::PRIVILEGE) {
            let shell = if ctx.ajax { Shell::Fragment(ctx.tags.clone()) } else { Shell::Page(ctx.page().await) };
            return Err(AppError::AclDenied { privilege: P::PRIVILEGE, shell });
        }
        Ok(Require(ctx, PhantomData))
    }
}

impl Ctx {
    /// Tagy + hlavička pre vykreslenie stránky (vyberie hlášky).
    pub async fn page(&self) -> Page {
        Page::build(&self.state, Some(&self.identity)).await
    }

    /// PRG redirect v rámci portletu (`redirect:/blacklist/…`).
    pub fn redirect(&self, path: &str) -> Response {
        redirect(&portlet_path(path))
    }

    /// Hodnota z lokálnej session.
    pub fn local_get<T: Clone + 'static>(&self, key: &'static str) -> Option<T> {
        self.state.local_sessions.get(self.local_session_id.as_deref(), key)
    }

    /// Zápis do lokálnej session; `Some(id)` = nová session, odpoveď musí poslať Set-Cookie.
    pub fn local_put<T: Send + Sync + 'static>(&self, key: &'static str, value: T) -> Option<String> {
        self.state.local_sessions.put(self.local_session_id.as_deref(), key, value)
    }

    /// Odstránenie z lokálnej session.
    pub fn local_remove(&self, key: &'static str) {
        self.state.local_sessions.remove(self.local_session_id.as_deref(), key);
    }

    /// Povinné číselné ID z parametra; chýba/nie je číslo → 400, záporné → 404 (Java `long` ho prijme, záznam neexistuje).
    pub async fn require_id(&self, raw: &Option<String>, what: &str) -> Result<u64, AppError> {
        let Some(id) = raw.as_deref().map(str::trim).and_then(|v| v.parse::<i64>().ok()) else {
            return Err(self.bad_request().await);
        };
        match u64::try_from(id) {
            Ok(id) => Ok(id),
            Err(_) => Err(self.not_found(&format!("{what} {id}")).await),
        }
    }

    /// 404 stránka (aj pre AJAX – Java vracia celú chybovú stránku).
    pub async fn not_found(&self, what: &str) -> AppError {
        tracing::debug!("Nenájdené: {what}");
        AppError::NotFound(self.page().await)
    }
```

```rust
use crm_web_rs::config::Config;
use crm_web_rs::{AppState, app};
use tracing_subscriber::EnvFilter;

#[tokio::main]
async fn main() {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new("info")))
        .init();
    let config = Config::from_env();
    let bind = config.bind;
    let state = AppState::production(config).unwrap_or_else(|e| fail("Konfigurácia appky zlyhala", &e));
    let listener = tokio::net::TcpListener::bind(bind).await.unwrap_or_else(|e| fail("Port sa nedá otvoriť", &e));
    tracing::info!("crm-web-rs počúva na {bind}");
    if let Err(e) = axum::serve(listener, app(state)).with_graceful_shutdown(shutdown_signal()).await {
        fail("Server zlyhal", &e);
    }
}

fn fail(what: &str, error: &dyn std::fmt::Display) -> ! {
    tracing::error!("{what}: {error}");
    std::process::exit(1)
}

async fn shutdown_signal() {
    let ctrl_c = async {
        let _ = tokio::signal::ctrl_c().await;
    };
    #[cfg(unix)]
    let terminate = async {
        if let Ok(mut signal) = tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate()) {
            signal.recv().await;
        }
    };
    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();
    tokio::select! {
        _ = ctrl_c => {},
        _ = terminate => {},
    }
}
```

```rust
//! Vyhľadávanie (Java `BlacklistSearchController`): render = GET, action = POST + redirect (PRG).
//! Kritériá žijú v lokálnej session ako `@SessionAttributes("searchCriteria")`.

use askama::Template;
use axum::response::Response;
use axum::routing::{get, post};
use axum::{Form, Router};

use crate::blacklist::forms::SearchForm;
use crate::blacklist::model::{BlacklistRecord, BlacklistState};
use crate::web::app::AppState;
use crate::web::errors::{html, with_cookie};
use crate::web::layout::LayoutModel;
use crate::web::portlet::{Ctx, Require, View};
use crate::web::tags::{FieldErrors, Tags, portlet_path};

const SEARCH_CRITERIA: &str = "searchCriteria";

/// Routy vyhľadávania.
pub fn routes() -> Router<AppState> {
    Router::new()
        .route(&portlet_path("/search"), get(search_page))
        .route(&portlet_path("/searchAction"), post(search_action))
        .route(&portlet_path("/searchresult"), get(search_result))
        .route(&portlet_path("/newSearch"), get(new_search))
}

#[derive(Template)]
#[template(path = "blacklist/search.html")]
struct SearchPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    form: SearchForm,
    errors: FieldErrors,
    states: &'static [BlacklistState],
}

#[derive(Template)]
#[template(path = "blacklist/searchresult.html")]
struct SearchResultPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    results: Vec<BlacklistRecord>,
}

async fn search_page(Require(ctx, _): Require<View>) -> Response {
    let form = ctx.local_get::<SearchForm>(SEARCH_CRITERIA).unwrap_or_default();
    render_search(&ctx, form, FieldErrors::default()).await
}

async fn search_action(Require(ctx, _): Require<View>, Form(posted): Form<SearchForm>) -> Response {
    let form = ctx.local_get::<SearchForm>(SEARCH_CRITERIA).unwrap_or_default().merge(posted);
    // Ako @SessionAttributes: naviazané kritériá sa uložia aj pri validačnej chybe.
    let new_session = ctx.local_put(SEARCH_CRITERIA, form.clone());
    let response = match form.validate() {
        // Validačná chyba sa vykreslí hneď (bez redirectu), aby ostali chyby pri poliach – ako render po action.
        Err(violations) => {
            let errors = FieldErrors::resolve(&violations, ctx.tags.messages());
            render_search(&ctx, form, errors).await
        }
        Ok(criteria) => {
            // Zdieľaná session: posledné kritériá vidí aj Java appka a stará appka.
            ctx.session.set(&form.to_shared()).await;
            if ctx.state.blacklist.search(&criteria).is_empty() {
                ctx.session.push_info("blacklist.search.noResult").await;
                ctx.redirect("/search")
            } else {
                ctx.redirect("/searchresult")
            }
        }
    };
    with_cookie(response, new_session)
}

async fn search_result(Require(ctx, _): Require<View>) -> Response {
    let form = ctx.local_get::<SearchForm>(SEARCH_CRITERIA).unwrap_or_default();
    // Hľadá sa znova (ako legacy render fáza) – výsledky sa v session nedržia.
    let results = ctx.state.blacklist.search(&form.criteria());
    let page = ctx.page().await;
    html(&SearchResultPage {
        tags: page.tags,
        layout: page.layout,
        title_key: "blacklist.result.title",
        privilege_filter: Some("BLACKLIST_VIEW"),
        results,
    })
}

/// Legacy „vyčistiť polia“ bola action fáza; je to len navigácia, preto GET.
async fn new_search(Require(ctx, _): Require<View>) -> Response {
    ctx.local_remove(SEARCH_CRITERIA);
    ctx.redirect("/search")
}

async fn render_search(ctx: &Ctx, form: SearchForm, errors: FieldErrors) -> Response {
    let page = ctx.page().await;
    html(&SearchPage {
        tags: page.tags,
        layout: page.layout,
        title_key: "blacklist.search.title",
        privilege_filter: Some("BLACKLIST_VIEW"),
        form,
        errors,
        states: BlacklistState::ALL,
    })
}
```

```rust
//! Detail záznamu (Java `BlacklistDetailController`): render `detail`, action `changeAction`/`addNoteAction`
//! a resource `removeIdentAction` (AJAX, vracia HTML fragment – JS na stránke sa nemení).

use askama::Template;
use axum::extract::Query;
use axum::response::Response;
use axum::routing::{get, post};
use axum::{Form, Router};
use serde::Deserialize;

use crate::blacklist::forms::{ChangeForm, NoteForm};
use crate::blacklist::model::{BlacklistRecord, BlacklistState, Identifier};
use crate::blacklist::service::BlacklistError;
use crate::session::keys::LastViewedRecord;
use crate::web::app::AppState;
use crate::web::errors::{AppError, html};
use crate::web::layout::LayoutModel;
use crate::web::portlet::{Ctx, Modify, Require, View};
use crate::web::tags::{FieldErrors, Tags, portlet_path};

/// Routy detailu.
pub fn routes() -> Router<AppState> {
    Router::new()
        .route(&portlet_path("/detail"), get(detail))
        .route(&portlet_path("/changeAction"), post(change))
        .route(&portlet_path("/addNoteAction"), post(add_note))
        .route(&portlet_path("/resource/removeIdentAction"), post(remove_identifier))
}

/// Parametre v URL (detailId ide v URL akcie ako v Jave). Reťazce – zlé číslo rieši `Ctx::require_id` (400/404).
#[derive(Debug, Deserialize)]
#[serde(rename_all = "camelCase")]
struct DetailParams {
    detail_id: Option<String>,
    ident_id: Option<String>,
}

#[derive(Template)]
#[template(path = "blacklist/detail.html")]
struct DetailPage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    record: BlacklistRecord,
    identifiers: Vec<Identifier>,
    detail_id: u64,
    error_key: &'static str,
    states: &'static [BlacklistState],
    change_form: ChangeForm,
    change_errors: FieldErrors,
    note_form: NoteForm,
    note_errors: FieldErrors,
}

#[derive(Template)]
#[template(path = "blacklist/fragments/identifiers.html")]
struct IdentifiersFragment {
    tags: Tags,
    identifiers: Vec<Identifier>,
    detail_id: u64,
    error_key: &'static str,
}

/// Formuláre detailu; pri validačnej chybe ostane odoslaný formulár s chybami (Java: model ho neprepíše).
struct DetailForms {
    change: ChangeForm,
    change_errors: FieldErrors,
    note: NoteForm,
    note_errors: FieldErrors,
}

impl DetailForms {
    fn for_record(record: &BlacklistRecord) -> Self {
        Self {
            change: ChangeForm::from_record(record),
            change_errors: FieldErrors::default(),
            note: NoteForm::default(),
            note_errors: FieldErrors::default(),
        }
    }
}

async fn detail(Require(ctx, _): Require<View>, Query(params): Query<DetailParams>) -> Result<Response, AppError> {
    let id = ctx.require_id(&params.detail_id, "záznam blacklistu").await?;
    let record = load(&ctx, id).await?;
    // Zdieľaná session: hlavička Java appky aj Liferay ukáže, s kým operátor naposledy pracoval.
    ctx.session.set(&LastViewedRecord { id, full_name: record.full_name() }).await;
    let forms = DetailForms::for_record(&record);
    Ok(render_detail(&ctx, record, forms).await)
}

async fn change(Require(ctx, _): Require<Modify>, Query(params): Query<DetailParams>, Form(form): Form<ChangeForm>)
    -> Result<Response, AppError> {
    let id = ctx.require_id(&params.detail_id, "záznam blacklistu").await?;
    match form.validate() {
        Err(violations) => {
            let record = load(&ctx, id).await?;
            let change_errors = FieldErrors::resolve(&violations, ctx.tags.messages());
            let forms = DetailForms { change: form, change_errors, ..DetailForms::for_record(&record) };
            Ok(render_detail(&ctx, record, forms).await)
        }
        Ok((state, valid_to)) => {
            if let Err(e) = ctx.state.blacklist.change(id, state, valid_to) {
                return Err(fail(&ctx, e).await);
            }
            ctx.session.push_info("blacklist.detail.changed").await;
            Ok(ctx.redirect(&format!("/detail?detailId={id}")))
        }
    }
}

async fn add_note(Require(ctx, _): Require<Modify>, Query(params): Query<DetailParams>, Form(form): Form<NoteForm>)
    -> Result<Response, AppError> {
    let id = ctx.require_id(&params.detail_id, "záznam blacklistu").await?;
    match form.validate() {
        Err(violations) => {
            let record = load(&ctx, id).await?;
            let note_errors = FieldErrors::resolve(&violations, ctx.tags.messages());
            let forms = DetailForms { note: form, note_errors, ..DetailForms::for_record(&record) };
            Ok(render_detail(&ctx, record, forms).await)
        }
        Ok(text) => {
            if let Err(e) = ctx.state.blacklist.add_note(id, &text, &ctx.identity.operator.display_name) {
                return Err(fail(&ctx, e).await);
            }
            ctx.session.push_info("blacklist.detail.noteAdded").await;
            Ok(ctx.redirect(&format!("/detail?detailId={id}")))
        }
    }
}

/// Resource fáza → AJAX endpoint, vracia HTML fragment ako legacy.
async fn remove_identifier(Require(ctx, _): Require<Modify>, Query(params): Query<DetailParams>)
    -> Result<Response, AppError> {
    let id = ctx.require_id(&params.detail_id, "záznam blacklistu").await?;
    let identifier_id = ctx.require_id(&params.ident_id, "identifikátor").await?;
    let (identifiers, error_key) = match ctx.state.blacklist.remove_identifier(id, identifier_id) {
        Ok(remaining) => (remaining, ""),
        Err(BlacklistError::Rule(key)) => (load(&ctx, id).await?.identifiers, key),
        Err(e) => return Err(fail(&ctx, e).await),
    };
    Ok(html(&IdentifiersFragment { tags: ctx.tags.clone(), identifiers, detail_id: id, error_key }))
}

async fn render_detail(ctx: &Ctx, record: BlacklistRecord, forms: DetailForms) -> Response {
    let page = ctx.page().await;
    html(&DetailPage {
        tags: page.tags,
        layout: page.layout,
        title_key: "blacklist.detail.title",
        privilege_filter: Some("BLACKLIST_VIEW"),
        identifiers: record.identifiers.clone(),
        detail_id: record.id,
        record,
        error_key: "",
        states: BlacklistState::ALL,
        change_form: forms.change,
        change_errors: forms.change_errors,
        note_form: forms.note,
        note_errors: forms.note_errors,
    })
}

async fn load(ctx: &Ctx, id: u64) -> Result<BlacklistRecord, AppError> {
    match ctx.state.blacklist.find_by_id(id) {
        Some(record) => Ok(record),
        None => Err(ctx.not_found(&format!("záznam blacklistu {id}")).await),
    }
}

async fn fail(ctx: &Ctx, error: BlacklistError) -> AppError {
    match error {
        BlacklistError::NotFound(what) => ctx.not_found(&what).await,
        BlacklistError::Rule(key) => {
            tracing::error!("Neošetrené pravidlo blacklistu: {key}");
            AppError::Internal
        }
    }
}
```

```rust
//! Nový záznam (Java `BlacklistCreateController`): render `create`, action `createAction`,
//! resource `refreshCreateConditionTypes`. Celý „portlet“ vyžaduje BLACKLIST_MODIFY.

use askama::Template;
use axum::extract::Query;
use axum::response::Response;
use axum::routing::{get, post};
use axum::{Form, Router};
use serde::Deserialize;

use crate::blacklist::forms::{CreateForm, parse_enum};
use crate::blacklist::model::{ConditionType, IdentifierType, StateReason};
use crate::web::app::AppState;
use crate::web::errors::{AppError, html};
use crate::web::layout::LayoutModel;
use crate::web::portlet::{Ctx, Modify, Require};
use crate::web::tags::{FieldErrors, Tags, portlet_path};

/// Routy nového záznamu.
pub fn routes() -> Router<AppState> {
    Router::new()
        .route(&portlet_path("/create"), get(create_page))
        .route(&portlet_path("/resource/refreshCreateConditionTypes"), get(refresh_condition_types))
        .route(&portlet_path("/createAction"), post(create_action))
}

#[derive(Debug, Deserialize)]
#[serde(rename_all = "camelCase")]
struct RefreshParams {
    state_reason: Option<String>,
}

#[derive(Template)]
#[template(path = "blacklist/create.html")]
struct CreatePage {
    tags: Tags,
    layout: LayoutModel,
    title_key: &'static str,
    privilege_filter: Option<&'static str>,
    form: CreateForm,
    errors: FieldErrors,
    state_reasons: &'static [StateReason],
    identifier_types: &'static [IdentifierType],
    condition_types: Vec<ConditionType>,
    selected_condition: String,
}

#[derive(Template)]
#[template(path = "blacklist/fragments/conditionTypes.html")]
struct ConditionTypesFragment {
    tags: Tags,
    condition_types: Vec<ConditionType>,
    selected_condition: String,
}

async fn create_page(Require(ctx, _): Require<Modify>) -> Response {
    let form = CreateForm::initial(ctx.state.clock.today());
    render_create(&ctx, form, FieldErrors::default()).await
}

/// Resource fáza → AJAX: po zmene dôvodu HTML fragment so zoznamom povolených podmienok.
async fn refresh_condition_types(Require(ctx, _): Require<Modify>, Query(params): Query<RefreshParams>)
    -> Result<Response, AppError> {
    let Ok(reason) = parse_enum(&params.state_reason, StateReason::from_name) else {
        return Err(ctx.bad_request().await);
    };
    Ok(html(&ConditionTypesFragment {
        tags: ctx.tags.clone(),
        condition_types: ctx.state.blacklist.allowed_condition_types(reason),
        selected_condition: String::new(),
    }))
}

async fn create_action(Require(ctx, _): Require<Modify>, Form(form): Form<CreateForm>) -> Response {
    let today = ctx.state.clock.today();
    let form = form.with_default_valid_from(today);
    let service = ctx.state.blacklist.clone();
    // Povolené kombinácie dôvod/podmienka určuje backend – preto pravidlo dostane funkciu služby.
    match form.validate(today, |reason| service.allowed_condition_types(reason)) {
        Err(violations) => {
            let errors = FieldErrors::resolve(&violations, ctx.tags.messages());
            render_create(&ctx, form, errors).await
        }
        Ok(command) => {
            let created = service.create(command);
            ctx.session.push_info("blacklist.create.created").await;
            ctx.redirect(&format!("/detail?detailId={}", created.id))
        }
    }
}

async fn render_create(ctx: &Ctx, form: CreateForm, errors: FieldErrors) -> Response {
    let condition_types = ctx.state.blacklist.allowed_condition_types(form.state_reason());
    let selected_condition = form.v("conditionType").to_string();
    let page = ctx.page().await;
    html(&CreatePage {
        tags: page.tags,
        layout: page.layout,
        title_key: "blacklist.create.title",
        privilege_filter: Some("BLACKLIST_MODIFY"),
        form,
        errors,
        state_reasons: StateReason::ALL,
        identifier_types: IdentifierType::ALL,
        condition_types,
        selected_condition,
    })
}
```

```markdown
# Ďalšia appka v inom jazyku za stranglerom

Overené v deme Rust kópiou (`crm-web-rs`). Appka v ľubovoľnom jazyku sa pripojí, ak dodrží tento kontrakt –
nič iné z Javy/Liferay nepotrebuje.

## Identita
- Cookie `SSO_ID` (Path=/, nastavuje SSO portál). Platný tvar overiť (`[A-Za-z0-9-]{1,64}`) – hodnota ide do URL aj do kľúča v Redise.
- `GET {sso}/api/sessions/{id}` → `{"operator":{"login","displayName"},"customer":{"customerId","displayName"}}`.
  404 = neprihlásený (stránka → `/sso/login?returnUrl=<url-encoded cesta>`, AJAX → 401); iná chyba/timeout = „SSO nedostupné“, nie odhlásenie.
- Krátke timeouty (1 s / 2 s) – SSO sa pýta pri každom requeste.

## Zdieľaná session
- Redis hash `crm:session:{SSO_ID}`, TTL 30 min obnovovať pri čítaní aj zápise.
- Polia s prefixom `APP_`: `APP_MESSAGES` (pole `{"level":"INFO|ERROR","key"}`), `APP_BLACKLIST_LAST_CRITERIA`, `APP_LAST_VIEWED_RECORD`.
- JSON: camelCase, enumy ako reťazce, `null` pre neodoslané polia; **neznáme polia ignorovať** (iná appka môže pridať pole skôr).
- Hlášky: zapisovať vždy celý nový zoznam; po zobrazení pole zmazať (zobrazia sa práve raz v ktorejkoľvek appke).
- Výpadok Redisu nesmie zhodiť request (timeout ~500 ms, log, pokračovať bez session) a po návrate Redisu sa treba znova pripojiť.
- Flag `crm:flags:session-read-source` patrí starej appke – nová ho len zobrazuje.

## Za jedným nginx
- Vlastný kontext (`/crm`, `/crm-rs`) a **vlastná session cookie s Path na kontext** – inak prepíše `JSESSIONID` Liferay alebo cookie inej appky.
- CSS témy ťahať z Liferay cez nginx (rovnaký vzhľad); mimo :8000 je stránka bez štýlu.
- AJAX rozlišovať hlavičkou `X-Requested-With: XMLHttpRequest` (fragment / 401 / 403 bez layoutu).

## Pasce
- Texty a statické súbory nekopírovať – čítať z jedného zdroja, inak sa appky rozídu.
- Regex `\d` v niektorých jazykoch berie aj Unicode číslice (Rust) – pre formáty identifikátorov `[0-9]`.
- Redirect po POST: Spring dáva 302, niektoré frameworky 303 – pre zhodné správanie nastaviť explicitne.
```
